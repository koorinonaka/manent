プライバシーポリシー

最終更新日: 2026 年 11 月 10 日

このページは、Windows 用のピン留めキャプチャツール Manent (以下「本アプリ」) が扱う情報を説明します。対象は Microsoft Store 版と、GitHub で配布するインストーラ版・ポータブル版です。

集める情報

本アプリは個人情報を集めません。アカウントの登録はありません。利用状況の統計、広告、クラッシュレポートの送信もありません。

撮った画面

撮った画面はメモリの中だけに置き、外部へ送りません。ファイルになるのは、利用者がコピーまたは保存の操作をしたときだけです。

  • コピーした画像は Windows のクリップボードに入ります。
  • 保存した画像は、利用者が選んだフォルダに書きます。既定のフォルダはピクチャです。
  • GIF をコピーするときは、一時フォルダ (%TEMP%\Manent) に GIF ファイルを作ります。

PC に保存する情報

  • 設定は %APPDATA%\Manent\settings.toml に保存します。
  • Windows の「既定のアプリ」で本アプリを画面キャプチャに選べるように、現在のユーザーのレジストリ (HKEY_CURRENT_USER) に本アプリを登録します。
  • サインイン時の起動とエクスプローラーの右クリックメニューは、設定でオンのときだけ同じレジストリに書きます。

これらは PC の中だけにあり、外部へ送りません。

通信

Microsoft Store 版は通信しません。更新は Microsoft Store が行います。

GitHub で配布する版は、更新の確認のためだけに通信します。

  • 起動の後と 24 時間ごとに、GitHub の API (api.github.com) へ最新のリリースを問い合わせます。
  • 利用者が設定の更新のボタンを押したときだけ、新しいインストーラを GitHub からダウンロードします。
  • 送る情報は通常の HTTPS のリクエストだけで、本アプリが独自の情報を付け加えることはありません。IP アドレスなどのリクエストの情報は GitHub が受け取り、GitHub のプライバシーステートメントに従って扱います。
  • 設定で更新の確認をオフにすると、本アプリは外部と一切通信しません。

第三者への提供

本アプリは情報を集めないため、第三者に提供する情報はありません。

このポリシーの変更

内容を変えるときは、このページを更新し、最終更新日を改めます。

問い合わせ

質問は GitHub の Issues で受け付けます。

Privacy Policy

Last updated: November 10, 2026

This page explains what information Manent, a pinning screen capture tool for Windows (“the app”), handles. It covers the Microsoft Store version and the installer and portable versions distributed on GitHub.

Information we collect

The app collects no personal information. There is no account. The app sends no usage statistics, no ads and no crash reports.

Your captures

Captures stay in memory and are never sent anywhere. They become files only when you copy or save them.

  • A copied image goes to the Windows clipboard.
  • A saved image is written to the folder you choose. The default is Pictures.
  • Copying a GIF writes a GIF file to the temporary folder (%TEMP%\Manent).

Information stored on your PC

  • Settings are stored in %APPDATA%\Manent\settings.toml.
  • The app registers itself in the current user's registry (HKEY_CURRENT_USER) so that you can choose it for screen capture in Windows Default apps.
  • Start at sign-in and the File Explorer context menu are written to the same registry only while they are on in Settings.

This information stays on your PC and is never sent anywhere.

Network

The Microsoft Store version makes no network connections. Microsoft Store handles its updates.

The versions distributed on GitHub connect only to check for updates.

  • After start-up and every 24 hours, the app asks the GitHub API (api.github.com) for the latest release.
  • Only when you press the Update button in Settings does the app download the new installer from GitHub.
  • The app sends an ordinary HTTPS request and adds no information of its own. GitHub receives the request details, such as your IP address, and handles them under the GitHub General Privacy Statement.
  • Turn off the update check in Settings, and the app makes no network connections at all.

Sharing with third parties

The app collects no information, so it has nothing to share with third parties.

Changes to this policy

When this policy changes, this page is updated along with the date above.
