# Microsoft Store 掲載情報 (日本語)

Partner Center の「ストア登録情報」の日本語 (ja-jp) に貼る原稿。文言は `site/index.html` の日本語版から作った。

## 製品名

Manent

## 短い説明

撮った画面をファイルにせず、撮った位置に等倍で残す Windows 11 のピン留めキャプチャツールです。GIF のピン、その場での書き込み、Ctrl で部品を選ぶ撮り方に対応します。

## 説明

Manent は、撮った画面をその場に残すピン留めキャプチャツールです。撮った画像は、撮った場所に等倍で残ります。ドラッグで動かし、ホイールで拡大・縮小し、不透明度を下げて下の画面と重ねられます。クリックを下の窓へ通せば、ピンを表示したまま裏のアプリを操作できます。

範囲を録画すると、止めた位置にそのまま GIF のピンが出ます。フィルムストリップで前後を切り詰め、要らないフレームを消してから、Ctrl+C で GIF ファイルとしてコピーできます。

矢印・直線・矩形・楕円・テキスト・番号バッジ・ペン・蛍光ペン・モザイクの 9 種類で書き込めます。書き込みは後から選んで動かせて、元に戻すこともできます。

Ctrl を押すと、カーソルの下のウインドウやボタンなどの部品が光ります。そのままクリックすれば、その範囲を撮れます。静止画のキーを押した時点で画面を止めるので、メニューやツールチップのように消えやすいものも撮れます。

ホットキーのほか、トレイのアイコンのクリックでも撮れます。Windows の「既定のアプリ」で Manent を選ぶと、Win+Shift+S でも開きます。エクスプローラーで画像を右クリックして「Manent でピン留め」を選ぶと、その画像がピンになります。

静止画・GIF・GIF の今のフレームをコピーでき、PNG か GIF で保存できます。GIF は縮小の倍率を 100〜25% から選べます。サイズの上限 (25〜1 MB) も選べ、超えるときは収まるまで縮めて書き出します。

画面は日本語と英語、ライトとダークのテーマに追従します。モニタごとに拡大率が違っても、ピンは撮った大きさのまま出ます。

Manent は個人情報を集めず、ストア版は通信しません。名前はラテン語の格言 Verba volant, scripta manent (言葉は飛び去り、書かれたものは残る) から取りました。

## 製品の機能 (1 行 1 項目)

- 撮った画像を、撮った位置に等倍のピンとして残す
- ピンはドラッグで移動、ホイールで拡大・縮小、不透明度を変えて下の画面と重ねられる
- クリックを下の窓へ通して、ピンを表示したまま裏のアプリを操作できる
- 範囲を録画すると、止めた位置に GIF のピンが出る
- フィルムストリップで GIF の前後の切り詰めとフレームの削除ができる
- 矢印・直線・矩形・楕円・テキスト・番号バッジ・ペン・蛍光ペン・モザイクの 9 種類で書き込める
- Ctrl を押すと、カーソルの下のウインドウや部品を選んで撮れる
- 静止画のキーを押した時点で画面を止めるので、メニューやツールチップも撮れる
- エクスプローラーの右クリックから、画像ファイルをピンにできる
- PNG と GIF で保存でき、GIF は縮小の倍率とサイズの上限を選べる
- 日本語と英語、ライトとダークのテーマに追従する
